# 2026-05-22 首页布局与图标基线

## 背景

首页经过多轮视觉修正后，用户明确确认当前整体布局效果已经达到目标，需要沉淀成后续修改的比较基准。

## 最终结论

- 当前首页整体布局视为有效基线，后续改动默认只能在此基础上做局部微调。
- 首页服务宫格图标必须满足：完整显示、视觉居中、位置一致。
- 首页服务图标当前标准资源目录固定为 `public/assets/service-icons-normalized/`。
- 对 `政府促消费`、`赚钱中心` 这类主体重心特殊的图标，可保留单独微调规则，不要求强制套用完全统一的公共定位。

## 影响范围

- `src/pages/HomePage.jsx`
- `src/styles.css`
- `public/assets/service-icons-normalized/`

## 执行规则

1. 若后续继续修首页图标，先看标准化资源是否需要调整。
2. 若只是 1 到 2 个图标有偏差，优先局部修，不先改公共容器。
3. 每次用户确认新的视觉版本后，必须覆盖更新本决策文档，而不是并列保留多个“最终版”。
