# 2026-05-28 全页面字体图标比例冻结基准

## 最高规则

- 本文记录的是当前 APK 运行态页面的字体大小、图标大小、控件尺寸和页面比例基准。
- 本文基准来自 `app-debug (6).apk` 恢复后的真实打包产物：`app/src/main/assets/www/assets/index-CQrF5bT3.css`。
- 后续所有开发都必须以本文为基准，不允许擅自改变字体大小、图标大小、控件高度、页面密度和主要间距比例。
- 如果未来确实需要变化，必须先由用户明确要求修改基准文档；否则任何页面开发、Bug 修复、定时器、接口或功能开发都不得顺手调整这些尺寸。

## 单位说明

- `cqw` 是当前移动页面容器宽度的百分比单位，`1cqw = 页面容器宽度的 1%`。
- 当前 APK/WebView 页面以 `100%` 宽度运行，因此 `cqw` 是主要视觉比例单位。
- 本文记录最终生效的覆盖层数值；早期 CSS 中被后续 `cqw` 规则覆盖的 px 值不作为基准。
