# 免费申请查询后台记录时间

## 结论

- 用户输入 6 位验证码并点击“免费申请查询”后，前端调用 `POST /api/credit-report-records`。
- 服务端以 `apply_time=NOW()` 写入点击时间，前端保存成功后进入查询记录页。
- 记录时间在展示和对账时至少精确到分。
- 写入失败时不进入报告页，提示用户稍后重试，避免出现未生成查询记录却能直接查看报告的流程。

## 实现边界

- 前端使用 `fetch(..., { keepalive: true })` 写入查询记录。
- 当前演示用户仍为 `demo`，报告地址仍为 `http://120.71.7.165:9724/xybg.pdf`。
- 查询记录页的 `GET` 读取逻辑不在本次变更范围。
