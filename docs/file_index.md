## 核心代码

### `src/pages/HomePage.jsx`
- 职责：首页主视图与服务宫格入口定义。
- 边界：负责首页服务图标引用路径、服务项顺序、跳转入口绑定。
- 风险：如果切回旧资源目录或热更新未生效，页面效果会与本地文件不一致。

### `src/styles.css`
- 职责：全局页面样式与首页宫格布局、图标容器、局部图标偏移规则。
- 边界：包含首页服务图标的公共尺寸、安全区、局部微调规则，以及信用报告 PDF 查看页工具栏样式。
- 风险：修改公共图标容器规则容易影响整组图标对齐，单图问题优先局部修；修改 PDF 工具栏样式时不要影响信用报告小程序顶部蓝色栏。

### `src/components/RemotePdfViewer.jsx`
- 职责：信用报告 PDF 查看页的远端 PDF 下载、PDF.js 渲染、页码翻页、页码输入跳转和放大缩小控制。
- 边界：只负责 PDF 内容区和灰色工具栏，不负责信用报告小程序顶部栏、查询记录或验证码逻辑。
- 风险：旧 Android WebView 需要继续使用 `pdfjs-dist/legacy` 与现有缓存下载链路；不要切回 PDF.js 直接远端 URL 加载。

### `src/creditReportRecord.js`
- 职责：信用报告查询日期的本地保存兜底、日期解析，以及服务器查询记录接口调用。
- 边界：当前服务器接口固定查询 `user_key=demo`，供查询记录页“未过期”分组读取 `queryDate`；真实用户识别和服务端写入不在此文件完成。
- 风险：如果 `120.71.7.165:9724/api/credit-report-record` 路由、字段名或 CORS 配置变化，查询记录页将不会显示未过期分组。

### `src/App.jsx`
- 职责：应用页面路由，以及信用报告查询记录页的未过期/已过期分组渲染。
- 边界：未过期日期来自服务器记录，前端按 7 天规则判断；已过期日期仍按“月底/顺延周六”规则生成最近 4 条。
- 风险：不要在查询记录页里重新引入本机日期作为未过期来源，除非用户明确要求本地演示模式。

### `public/assets/service-icons-normalized/`
- 职责：首页服务宫格当前标准化图标资源目录。
- 边界：用于解决不同图标原始透明边、主体大小和视觉中心不一致的问题。
- 风险：若新增图标未经标准化直接放入页面，容易再次出现截断、偏移或大小不一致。

### `public/assets/service-icons-icon-crops-direct/`
- 职责：首页服务图标的中间素材来源。
- 边界：可作为重新标准化时的原始输入，不直接视为最终上线展示基线。
- 风险：透明边和主体重心并不完全一致，直接引用会造成位置偏差。
